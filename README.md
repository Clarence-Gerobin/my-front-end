# ⚛️ React + Vite

### 🏛️ PUP-Biñan Campus Portfolio Builder
> This is the **front-end repository** for the PUP-Biñan Campus Portfolio Builder. 
> 
> This application provides a modern, centralized platform for students to register and showcase their diverse skill sets to the campus community.

---

### 🛠️ Technical Stack

* **Framework:** `React.js` (Vite) ⚡
* **Styling:** `CSS3`
    * **Flexbox** for responsive centering.
    * **Backdrop-filter** for the frosted glass effect.
    * **RGBA Transparency** for the themed UI.
* **Assets:** Localized image assets for optimized **offline-first** performance. 📂

---

### 📋 Key Features
* **Centralized Registry:** A single point for student skill documentation.
* **Modern UI:** Glassmorphism design tailored to PUP institutional colors.
* **Device Responsive:** Seamlessly aligns on desktop, laptop, and mobile screens.
